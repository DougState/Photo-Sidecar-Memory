# Session Notes

One Markdown file per meaningful session. Suggested naming:

```
YYYY-MM-DD-short-slug.md
```

Each file should contain:

- **Goal** — what you set out to do
- **Context** — relevant prior state, branch, feature IDs touched
- **What happened** — narrative log of decisions and surprises
- **Outcome** — what got committed, what's still in flight
- **Followups** — items to surface in `feature_list.json` or the next session's notes

The newest session goes at the bottom of the directory listing (date prefix sorts naturally). Treat these as durable artifacts — they're the breadcrumbs the next agent will follow.
